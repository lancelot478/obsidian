# 当在问问题时有 “记录” “写入文件” 的要求时，按照下面的规则记录，否则不记录。

- 采用一问一答的方式与用户交互
- 每次问答完成后，将问题和完整详细回答记录在文件中。
- 如果该项目为 zserver， 或者父目录中有zserver,文件路径为`battle_server.md`。
- 如果该项目为 main ,则文件路径为`battle_client.md`。
- 若 上述文件 不存在则自动创建，已存在则追加新内容
- 若 上述文件 不存在则自动创建，已存在则追加新内容
- 记录格式：以 `## Q{序号}: {问题}` 作为标题，下方为结构化的回答内容
- 在 md 文件开头维护一个"目录"区域，使用 Obsidian wikilink 语法链接到对应标题：
    - 目录链接格式：`- [[#Q{序号}: {标题}]]`
    - 使用 `[[#标题全文]]` 的方式引用同文档内的标题，标题文本需与实际标题完全一致
    - 例如标题 `## Q1: 伊朗局势` 的目录链接为 `- [[#Q1: 伊朗局势]]`
    - 新增问题时同步更新目录

- 打印日志时，如果没有日志管理类，新建一个日志管理文件 battle_test_log.go,然后把所有后续日志的入口定位一个入口，每次打印新加一个枚举，根据枚举类型打印传入的参数和内容。
